# 2026-W38 Agent Skills 周报

## 本周有意义变化

- 精选清单从 24 项扩展到 32 项，新增代码评审、上下文工程、TDD、本地模型、视觉训练、实验追踪、测试缺口审计和 MCP 安全审计。
- Tools 从单一 HTML 报告栏目扩展为 4 类、24 项：HTML 报告、浏览器自动化、评测与可观测性、Skill 与 Agent 安全。
- Tools 的 Markdown 和网页改由结构化 JSON 自动生成，CI 会拒绝过期的生成文件。
- 网站首页增加任务入口、信任说明、运行状态筛选和一键复制安装命令。
- 精选数据升级到 schema v2，每项独立记录核验日期、版本固定状态和运行证据。

## 新增精选

| 方向 | Skill | 采用判断 |
|---|---|---|
| 工程质量 | `context-engineering`、`test-driven-development`、`code-review-and-quality` | 纯指令型、低风险，适合优先试点 |
| 算法工程 | `huggingface-local-models`、`huggingface-vision-trainer`、`huggingface-trackio` | 来源可靠；模型下载、云 GPU、凭据和远端指标需要单独审查 |
| 验证与安全 | `test-gap-audit`、`mcp-security-audit` | 默认审计型，适合合并前或配置上线前使用 |

## 观察项

`eval-driven-dev` 能为 Python LLM 应用搭建端到端评测，但其初始化流程会升级依赖并启动后台 Web 服务。本周仅加入观察清单，待隔离环境审查后再决定是否推荐。
