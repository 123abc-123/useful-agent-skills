# 每周变化报告

每周报告只记录影响选型的变化：新增精选项、快速增长但待观察的项目、兼容性变化、重要 Release、归档、链接失效和安全问题。

新报告文件名使用发布日期 `YYYY-MM-DD.md`，历史 `YYYY-Www.md` 保留，内容包含：

- 本周新增或移除；
- 榜单趋势与可能原因；
- 已完成的源码、安全和兼容性核验；
- Pi/OpenCode 实机测试变化；
- 下周建议评估的候选项。

没有有意义变化时不创建空报告。
